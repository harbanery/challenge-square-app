## Built With

- React.js
- Redux
- Tailwind CSS
- Express.js
- MySQL

## Getting Started

### Installation

1. Clone Repo

   ```sh
   git clone https://github.com/harbanery/challenge-square-app.git
   ```

2. Go to folder directory

   ```bash
   cd challenge-square-app
   ```

3. Install NPM packages

   ```sh
   npm install
   ```

### Setup Environment Variables

1. Create a `.env` or `.env.local` file in your local root directory.

2. Add the example variables from `.env.example` to the `.env` or `.env.local` file.

### Running the Application

1. Start the development server:

   ```sh
   npm run dev

   npm run dev-be

   npm run migrate // for migration

   npm run seed // for seeder
   ```

2. Open your browser and locally navigate to:

   ```sh
   http://localhost:5173 // as front-end

   http://localhost:3000 // as back-end
   ```
